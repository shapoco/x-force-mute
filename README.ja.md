# X Force Mute

[English README](README.md)

**X (Twitter)** のポストを screen name・キーワード・正規表現で非表示にする [Tampermonkey](https://www.tampermonkey.net/) 用ユーザースクリプトです。

X には特定のユーザーをミュートする機能がありますが、**リストでは効かず**、ミュートしたはずのユーザーのポストが表示されてしまいます。このスクリプトはリストを含むすべてのタイムラインでポストを非表示にします。

## 特徴

- **screen name** (`@example`) によるミュートと、本文に対する **キーワード / 正規表現** によるミュートに対応。
- **リスト**はもちろん、ホーム・検索結果・プロフィールなど、あらゆるタイムラインで動作します。
- リポスト・引用リポストにも対応:
  - ミュート対象のユーザーによるリポストを非表示
  - ミュート対象のユーザーのポストのリポストを非表示
  - **引用されたポスト**がマッチした場合は、それを引用したポストごと非表示
- ミュート対象ユーザーの**プロフィールページ** (`x.com/username`) では、そのユーザー自身の `@username` ルールは無視され、ポストが表示されます (自分で見に行った場合は隠さない)。
- 設定 UI はページ右下の 🙈 ボタンから開けます。
- 設定はユーザースクリプトマネージャに保存されます。スクリプトが設定を外部に送信することはありません (詳細は「注意事項」参照)。

## インストール

1. ユーザースクリプトマネージャをインストールします。[Tampermonkey](https://www.tampermonkey.net/) を推奨しますが、Violentmonkey でも動作します。
2. 以下のリンクを開き、マネージャの表示に従ってインストールします。

   **[x-force-mute.user.js をインストール](https://raw.githubusercontent.com/shapoco/x-force-mute/main/dist/x-force-mute.user.js)**

   （中身を先に確認したい場合は [`dist/x-force-mute.user.js`](https://github.com/shapoco/x-force-mute/blob/main/dist/x-force-mute.user.js) を参照してください）
3. インストールの確認ダイアログで承認し、X を再読み込みします。

## 使い方

1. [x.com](https://x.com/) を開き、ページ**右下の 🙈 ボタン**をクリックします。
2. テキストボックスにミュート条件を **1 行に 1 つずつ** 入力します。
3. **Save** を押します。再読み込みせずにその場でタイムラインに反映されます。

`Cancel` を押すと編集内容を破棄してダイアログを閉じます。<kbd>Esc</kbd> でも閉じられ、<kbd>Ctrl</kbd>+<kbd>Enter</kbd> で保存できます。

ミュート条件が設定されている間、🙈 ボタンには青い枠が付きます。ボタンにマウスを乗せると、そのページで現在非表示になっているポストの件数が表示されます。

### 記述方法

| 行 | 意味 |
| --- | --- |
| `@screen_name` | このユーザーのポストを非表示にします。リポストした人、引用されたポストの投稿者にもマッチします。大文字小文字は区別しません。 |
| `/正規表現/` | 本文がこの正規表現にマッチするポストを非表示にします。フラグを省略した場合は `i`（大文字小文字を区別しない）が使われます。 |
| `/正規表現/フラグ` | 同上。[JavaScript の正規表現フラグ](https://developer.mozilla.org/ja/docs/Web/JavaScript/Reference/Global_Objects/RegExp)を明示的に指定します（`g` と `y` は無視されます）。 |
| それ以外 | 本文にこの文字列を含むポストを非表示にします。大文字小文字は区別しません。 |

空行は無視されます。`@` の行は screen name の部分だけが使われ、それ以降（`/status/...` やクエリ文字列など）は捨てられるので、プロフィールの URL の一部を貼り付けても構いません。

### 記述例

```
@spam_account
@another_user
いますぐ購入
/(?:速報|拡散希望)/
/^\s*おは\s*$/
```

この例では、`@spam_account` と `@another_user` によるポスト・リポスト・引用リポストと、本文に「いますぐ購入」を含むポスト、「速報」または「拡散希望」を含むポスト、本文が「おは」だけのポストが非表示になります。

## 注意事項

- キーワード・正規表現は**ポストの本文のみ**（そのポストの本文と、引用されたポストの本文）を対象にマッチします。表示名・画像の代替テキスト・リンクカードの見出しなどは対象外です。
- 判定はページに描画された内容に対して行われるため、タイムラインに現れた時点で非表示になります。X 側に何かを通知するわけではなく、単に表示されなくなるだけです。
- 設定はユーザースクリプトマネージャのストレージ (`GM_setValue`) にブラウザプロファイル単位で保存されます。利用できない場合は `localStorage` にフォールバックします。
- 設定内容がこのスクリプトによって端末外へ送信されることはありません。保存先はブラウザ内のみです。
- 保存された設定の安全性 (他のスクリプトや拡張機能からの読み取り、端末外への同期など) は、お使いのブラウザおよびユーザースクリプトマネージャ (拡張機能) のセキュリティに準じます。
- 設定 UI の表示言語は英語です。
